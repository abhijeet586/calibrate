## 📌 Executive Summary

**Calibrate Cloud** is an enterprise-grade cloud-native education and verification ecosystem designed to bridge the chasm between static academic curricula and dynamic, real-time tech industry hiring demands. 

Unlike standard course management systems, Calibrate Cloud introduces a **closed-loop proof-of-work pipeline**:
1. **CDC Administrators** track real-time hiring trends and calibrate career track requirements (e.g. Cloud Architect, DevOps, Full-Stack, AI/ML).
2. **Students** follow personalized milestone roadmaps and submit tangible, cryptographic proof-of-work deliverables (source code, architecture diagrams, build logs) directly into **Amazon S3** via presigned URLs generated by **AWS Lambda**.
3. **Faculty Mentors** audit student submissions, verify skill proficiencies, and trigger automated **Amazon SNS** notification dispatches, updating multi-axis skill gap radar models.

## ☁️ AWS Cloud Services Integrated

| AWS Service | Functional Role in Calibrate Cloud |
|---|---|
| **AWS Amplify** | Automated CI/CD pipeline, full-stack SSR hosting, edge performance |
| **Amazon S3** | Secure, durable object storage for student proof-of-work deliverables |
| **AWS Lambda** | Serverless compute generating time-limited S3 presigned upload URLs |
| **Amazon API Gateway** | Managed RESTful interface routing evidence requests to Lambda microservices |
| **Amazon SNS** | Push notification topic dispatching instant review alerts to mentors & students |
| **Amazon CloudWatch** | Centralized diagnostic logging, invocation telemetry, and execution metrics |
| **AWS IAM** | Granular least-privilege policies isolating service execution roles |

## 🚀 Key Features

- **Direct-to-Cloud Proof-of-Work Vault**: Secure client-side uploads directly to S3 via temporary presigned URLs, bypassing application server bottlenecks.
- **Multi-Axis Skill Gap Radar**: Dynamic visual analytics comparing student verified competencies against active market expectations.
- **Role-Based Access Control (RBAC)**: Edge-enforced routing separating Student, Faculty Mentor, and CDC Administrative portals.
- **Market Intelligence Telemetry**: Curated industry trends and hiring insights broadcast by career development administrators.
- **Tamper-Resistant Review Audit**: Verifiable history of mentor approvals, proficiency scores, and timestamped feedback.

## 💻 Local Development Setup

### 1. Prerequisites
- Node.js `v18+` (v20+ recommended)
- Git

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/AbhijeetSenapati/calibrate.git calibrate-cloud
cd calibrate-cloud

# Install dependencies
npm install
```

### 3. Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view Calibrate Cloud locally.

### 5. Production Build
```bash
npm run build
npm run start
```
